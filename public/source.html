Open source

Saajha Captions is a focused community captioning edition in Nubri’s ScreenStudio Linux repository. It carries forward the local Whisper approach as a separate browser implementation; it does not depend on the unfinished desktop recorder.

Browse the project on GitHub.

The application code is available under the MIT license. Download the source, build instructions and model checksums. Model weights are fetched separately from an immutable upstream revision.
